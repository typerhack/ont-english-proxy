# ont-english-proxy

**رابط وب مودم فیبر نوری هواوی (GPON / ONT) را حتی با فریم‌ور چینی، به زبان انگلیسی ببینید.**

بسیاری از مودم‌های فیبر نوری هواوی (مثلاً `EG8145X6`) با فریم‌ور نسخهٔ چین عرضه می‌شوند و صفحهٔ تنظیمات آن‌ها
فقط به زبان چینی نمایش داده می‌شود. فایل‌های زبان انگلیسی داخل خود مودم وجود دارند، اما فریم‌ور زبان را روی چینی
قفل کرده و گزینهٔ تغییر زبان را پنهان کرده است. معمولاً ارائه‌دهندهٔ اینترنت هم آپدیتی برای آن ارائه نمی‌دهد.

`ont-english-proxy` یک برنامهٔ کوچک است که روی کامپیوتر خودتان اجرا می‌شود، بین مرورگر و مودم قرار می‌گیرد
و همان صفحهٔ تنظیمات را به انگلیسی نشان می‌دهد:

- **هیچ تغییری در مودم ایجاد نمی‌شود.** بدون فلش کردن، بدون تغییر تنظیمات، بدون آپدیت فریم‌ور.
- **نیازی به نصب چیزی نیست** جز پایتون. فقط یک فایل، بدون پکیج اضافه.
- روی **مک (macOS)، لینوکس و ویندوز** کار می‌کند.
- منو، صفحات تنظیمات و لاگ‌ها ترجمه می‌شوند. اگر متنی هنوز چینی مانده، اضافه کردنش ساده است.

</div>

```
Browser  ──►  http://127.0.0.1:8181  (ont-english-proxy)  ──►  http://192.168.100.1  (modem)
```

## ۱. آیا مودم من پشتیبانی می‌شود؟

تست‌شده:

| مدل | فریم‌ور | نتیجه |
|---|---|---|
| EG8145X6 | V5R020C00S080 | کار می‌کند: منو، صفحات تنظیمات، لاگ‌ها |

احتمالاً روی سایر مودم‌های هواوی که صفحهٔ ورودشان در آدرس `http://192.168.100.1` است هم کار می‌کند.

**تست سریع:** وقتی صفحهٔ ورود مودم باز است، این آدرس را در مرورگر باز کنید:
`http://192.168.100.1/frameaspdes/english/ssmpdes.js`
اگر متن انگلیسی دیدید، فایل‌های زبان انگلیسی روی مودم شما هست و این برنامه باید کار کند.

روی مدل دیگری امتحان کردید؟ لطفاً در بخش Issues مدل و نسخهٔ فریم‌ور را بنویسید
(لطفاً **شمارهٔ سریال، IP، MAC یا اسکرین‌شات حاوی اطلاعات شخصی** نفرستید).

## ۲. نصب پایتون

به **پایتون ۳.۷ یا جدیدتر** نیاز دارید. در ترمینال بررسی کنید:

| سیستم‌عامل | بررسی | اگر نصب نیست |
|---|---|---|
| **مک** | برنامهٔ *Terminal* را باز کنید و بزنید `python3 --version` | پیشنهاد نصب «developer tools» را قبول کنید، یا از [python.org](https://www.python.org/downloads/) نصب کنید، یا `brew install python` |
| **ویندوز** | *Command Prompt* را باز کنید و بزنید `py --version` | از [python.org](https://www.python.org/downloads/) نصب کنید (گزینهٔ «py launcher» تیک داشته باشد) |
| **لینوکس** | `python3 --version` | `sudo apt install python3` (دبیان/اوبونتو) یا `sudo dnf install python3` (فدورا) |

چیز دیگری لازم نیست؛ نیازی به `pip install` نیست.

- لینوکس: راست‌کلیک ← *Open in Terminal*

## ۴. اجرا

۱. اگر در مرورگر وارد مودم شده‌اید، **اول خارج شوید (Logout)**. مودم در هر لحظه فقط یک ورود مدیر را قبول می‌کند.

۲. در پوشهٔ برنامه این دستور را اجرا کنید:

| سیستم‌عامل | دستور |
|---|---|
| مک / لینوکس | `python3 ont_english_proxy.py --open` |
| ویندوز | `py ont_english_proxy.py --open` |

باید چیزی شبیه این ببینید:

</div>

```
[ont-english-proxy] translations loaded: 90 menu names, 42 replacements, 0 dictionary overrides
[ont-english-proxy] http://127.0.0.1:8181  ->  http://192.168.100.1   (Ctrl+C to stop)
```

<div dir="rtl">

۳. مرورگر آدرس **http://127.0.0.1:8181** را باز می‌کند. با همان نام کاربری و رمز همیشگی مودم وارد شوید.
حالا صفحه‌ها انگلیسی هستند.

۴. تا وقتی از آن استفاده می‌کنید، پنجرهٔ ترمینال را باز نگه دارید.

> نکته: ترجمهٔ خودکار مرورگر (Google Translate) را برای این صفحه خاموش کنید تا نتیجهٔ واقعی را ببینید.

### اجرا در پس‌زمینه (اختیاری)

| سیستم‌عامل | شروع | توقف |
|---|---|---|
| مک / لینوکس | `nohup python3 ont_english_proxy.py > proxy.log 2>&1 &` | `pkill -f ont_english_proxy.py` |
| ویندوز | `start "" pyw ont_english_proxy.py` | در Task Manager، `pythonw.exe` را ببندید |

## ۵. توقف

در پنجرهٔ ترمینالی که برنامه در آن اجرا شده، کلیدهای **Ctrl+C** را بزنید.
بعد از آن می‌توانید مثل قبل مستقیم از `http://192.168.100.1` استفاده کنید.

## ۶. به‌روزرسانی

- **با git:** در پوشهٔ برنامه بزنید `git pull`
- **بدون git:** دوباره ZIP را دانلود کنید و جایگزین کنید. اگر ترجمه‌های خودتان را اضافه کرده‌اید، از `translations.json` نسخهٔ پشتیبان بگیرید.

## ۷. گزینه‌ها

</div>

```
python3 ont_english_proxy.py [options]

--port 8181          local port (e.g. --port 9000 if 8181 is busy)
--upstream HOST[:P]  modem address (default 192.168.100.1)
--listen 127.0.0.1   listen address; keep it local
--translations FILE  use a different translations file
--open               open the browser automatically
-v, --verbose        log full request lines (don't share these logs)
```

<div dir="rtl">

مثلاً اگر آدرس مودم شما فرق دارد: `python3 ont_english_proxy.py --upstream 192.168.1.1 --open`

## ۸. رفع مشکلات

| مشکل | راه‌حل |
|---|---|
| خطای `cannot listen on 127.0.0.1:8181 … already in use` | برنامه از قبل در حال اجراست (اول آن را ببندید) یا از `--port 9000` استفاده کنید |
| پیام `modem unreachable` در مرورگر | بررسی کنید `http://192.168.100.1` مستقیم باز می‌شود؛ اگر آدرس مودم فرق دارد از `--upstream` استفاده کنید |
| صفحهٔ ورود باز می‌شود ولی ورود انجام نمی‌شود | از مودم در همهٔ تب‌ها و دستگاه‌های دیگر خارج شوید، یک دقیقه صبر کنید و دوباره امتحان کنید |
| هنوز بعضی متن‌ها چینی است | برای چند متن کم‌کاربرد طبیعی است. بخش ۹ را ببینید |
| بعد از ویرایش ترجمه‌ها تغییری دیده نمی‌شود | صفحه را رفرش کنید (مک: Cmd+Shift+R، ویندوز: Ctrl+F5) |
| ویندوز: `python3` شناخته نمی‌شود | به جای `python3` از `py` استفاده کنید |

## ۹. ترجمهٔ متن‌های چینی باقی‌مانده

همهٔ ترجمه‌ها در فایل **`translations.json`** هستند. با هر ویرایشگر متنی بازش کنید؛ برنامه تغییرات را خودکار
می‌خواند و فقط کافی است صفحه را رفرش کنید.

| بخش | کاربرد | مثال |
|---|---|---|
| `menu` | نام دقیق منوها و صفحات | `"首页": "Home"` |
| `replace` | متن در هر جای صفحات و لاگ‌ها | `"已连接": "Connected"` |
| `dictionaries` | برچسب‌هایی که در فایل‌های انگلیسی مودم نیستند | `"DevInfoDes": { "somekey": "English text" }` |

قوانین: نام منو حداکثر ۲۰ کاراکتر و بدون `&`؛ در ترجمه‌ها از کوتیشن (`"` و `'`) و بک‌اسلش (`\`) استفاده نکنید.

ترجمهٔ جاافتاده‌ای پیدا کردید؟ لطفاً آن را به اشتراک بگذارید تا همه استفاده کنند (بخش ۱۲).

## ۱۰. ذخیرهٔ تنظیمات از طریق این برنامه

تغییراتی که از طریق این برنامه **Apply/Save** می‌کنید **واقعاً روی مودم ذخیره می‌شوند**؛ برنامه آن‌ها را بدون
تغییر به مودم می‌فرستد و فقط ظاهر صفحه را عوض می‌کند. بعد از ذخیره، صفحه را رفرش کنید تا مطمئن شوید مقدار ثبت شده.
برای تغییرات حساس (WAN، احراز هویت PON/ONT، فریم‌ور) شاید بهتر باشد مستقیم از صفحهٔ اصلی مودم استفاده کنید.

## ۱۱. این برنامه چطور کار می‌کند؟

| کاری که انجام می‌دهد | دلیل |
|---|---|
| درخواست فایل‌های `…/chinese/…` را به `…/english/…` تبدیل می‌کند | فایل‌های انگلیسی روی خود مودم هست، فقط هیچ‌وقت درخواست نمی‌شوند |
| در صفحات `curLanguage = 'chinese'` را به `'english'` تغییر می‌دهد | صفحات از حالت انگلیسی خود هواوی استفاده می‌کنند |
| برچسب‌های بدون ترجمه اول چینی نمایش داده می‌شوند و بعد از `translations.json` ترجمه می‌شوند | هیچ متنی خالی نمی‌ماند |
| نام منوها از بخش `menu` در `translations.json` گرفته می‌شود | منو روی مودم فقط چینی است |
| متن‌های کدشدهٔ چینی در لاگ‌ها رمزگشایی و ترجمه می‌شوند | لاگ‌ها به صورت `\uXXXX` ارسال می‌شوند |

کوکی‌ها، توکن‌های ورود و فرم‌ها **بدون هیچ تغییری** به مودم فرستاده می‌شوند.

## ۱۲. مشارکت

ترجمه، رفع اشکال و گزارش مدل‌های دیگر با کمال میل پذیرفته می‌شود. مراحل در
[بخش Contributing نسخهٔ انگلیسی](README.md#12-contributing) آمده است.
پیش از هر کامیت، قوانین [AGENTS.md](AGENTS.md) را رعایت کنید.

**مهم‌ترین قانون:** هیچ‌وقت چیزی از مودم یا کامپیوتر خودتان کامیت نکنید: شمارهٔ سریال، آدرس MAC یا IP، رمز عبور،
کوکی، توکن، لاگ، نام وای‌فای، مسیر فایل‌ها یا فایل‌های خود هواوی. از مثال‌های ساختگی استفاده کنید.
هوک‌های حریم خصوصی این قانون را بررسی می‌کنند و زمان کامیت‌ها را هم به UTC تبدیل می‌کنند تا منطقهٔ زمانی شما فاش نشود.
برای فعال کردن هوک‌ها:

</div>

```
git config core.hooksPath .githooks
```

### محافظت از منطقهٔ زمانی: پیش از push حتماً بخوانید

git به‌طور معمول **منطقهٔ زمانی شما** (مثلاً `+0330`) را در هر کامیت ثبت می‌کند و این نشان می‌دهد در کدام منطقه
زندگی می‌کنید. این مخزن **فقط زمان UTC** (`+0000`) را قبول می‌کند:

- اگر هوک‌ها فعال باشند، کامیت‌های معمولی خودکار به UTC تبدیل می‌شوند و لازم نیست کاری بکنید.
- اگر push **مسدود شد** (پیام «these commits contain your local timezone»)، که معمولاً بعد از rebase یا cherry-pick
  یا کامیت بدون هوک پیش می‌آید، کامیت‌ها را اصلاح کنید و دوباره push کنید:

</div>

```
# macOS / Linux / Git Bash
TZ=UTC0 git rebase --ignore-date origin/main

# Windows PowerShell
$env:TZ='UTC0'; git rebase --ignore-date origin/main; Remove-Item Env:TZ

# Windows cmd
set TZ=UTC0 && git rebase --ignore-date origin/main && set TZ=
```

<div dir="rtl">

سپس مثل همیشه `git push` کنید.

- اگر بدون هوک کامیت می‌کنید، خودتان در ابتدای دستور بنویسید: `TZ=UTC0 git commit -m "…"`

## ۱۳. حریم خصوصی و امنیت

- برنامه فقط روی `127.0.0.1` اجرا می‌شود، پس دستگاه‌های دیگر شبکه نمی‌توانند از آن استفاده کنند.
  روی شبکه‌ای که به آن اعتماد ندارید از `--listen 0.0.0.0` استفاده نکنید؛ ارتباط با مودم رمزنگاری نشده (HTTP) است.
- رمز عبور و نشست (session) شما هیچ‌جا ذخیره یا ثبت نمی‌شود.
- هیچ داده‌ای از شبکهٔ شما خارج نمی‌شود؛ برنامه فقط با مودم شما ارتباط دارد.
